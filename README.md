# DocRunnel — веб-демо для Vercel

`web/` содержит исходники интерфейса и конфигурацию сборки. Сборка под Vercel — **просто автономное веб-демо** без входа, паролей, учётных записей и серверной обработки документов.

Для Preview-деплоя из этой папки выполните `npx vercel`. При импорте всего репозитория укажите `web` в поле **Root Directory**. Vercel использует Node.js 24, команду `npm run build:preview` и каталог `dist`. Переменные окружения не требуются.

Локальная проверка из этой папки:

```sh
npm ci
npm run dev
```

Откройте **«Меню схемы» → «Библиотека шаблонов»** и выберите типовой шаблон договора. Добавьте узел через каталог **«Узлы»** или поиск на холсте и сохраните черновик. После перезагрузки его можно открыть в разделе **«Схемы»**. В каталоге есть синтетические примеры личного и программируемого узлов, которые можно открыть и изменить.

Веб-демо сохраняет схемы и узлы только в хранилище текущего браузера и не отправляет запросов к серверному API. Публичная сборка включает только синтетические примеры. Загрузка и обработка PDF/DOCX, исполнение Starlark на документах, экспорт CSV/JSON/XLSX и администрирование доступны в локальной версии Docker.

Официальный справочник [Vite на Vercel](https://vercel.com/docs/frameworks/frontend/vite).
