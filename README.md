# DocRunnel — автономное веб-демо (статика)

`web/` содержит исходники интерфейса и конфигурацию сборки. Статическая сборка (`npm run build:preview`) — это **автономное веб-демо**, которое полностью работает в браузере пользователя без сервера, входа, паролей и учётных записей.

## Что работает прямо в браузере

- Редактор графа (вкладки, шаблоны, каталог узлов, экспорт/импорт `схема_*.json`, сохранение схем и личных узлов в `localStorage`).
- **Загрузка до 3 тестовых файлов** PDF (с текстовым слоем) или DOCX (до 20 МБ каждый) — файлы не покидают браузер.
- **Реальная обработка документов в браузере**: предпросмотр результата, предпросмотр отдельного узла, пакетный запуск по загруженным файлам, ветвление на ручную проверку, дедупликация, ссылки на исходные цитаты и открытие оригинала.
- **Выгрузка результатов** в CSV, JSON и XLSX (формируются локально в браузере).

AI-генерация схем, Starlark, узлы «Сборка записи» и «Таблица», серверная очередь, аудит и управление пользователями доступны в локальной Docker-версии. Импортированную схему с серверными узлами можно открыть и сохранить как черновик. Предпросмотр доступен для узлов, которые выполняются в браузере вместе со всеми своими зависимостями.

## Сборка и деплой (Vercel, GitHub Pages, GitFlic Pages, Cloudflare Pages и др.)

Сборка использует относительные пути (`base: "./"`), поэтому каталог `dist/` открывается на любом статическом хостинге — как в корне домена (`/`), так и в подпапке (`/DocRunnel/`).

```sh
npm ci
npm run build:preview
```

- **GitHub Pages**: перенесите содержимое `web/` в корень репозитория для демо. Файлы `package.json`, `package-lock.json` и `.github/workflows/pages.yml` должны находиться по этим путям от корня. Workflow соберёт и опубликует `dist/`.
- **GitFlic Pages / российский хостинг (без VPN)**: соберите `dist/` командой `npm run build:preview` и опубликуйте содержимое `web/dist`.
- **Vercel**: укажите `web` в поле **Root Directory** (или выполните `npx vercel` из `web/`). Команда сборки — `npm run build:preview`, каталог вывода — `dist`, переменные окружения не требуются.

Локальный просмотр демо:

```sh
npm ci
npm run dev
```
